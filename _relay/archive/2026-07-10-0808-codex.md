# Handoff - Candidate Disclosure Security Pass

## Current state
- Candidate-facing disclosure policy now uses an allowlist salary boundary:
  compensation topic + not a safe candidate-target/ recruiter-deferral move = blocked.
- The old salary inference and exact salary scans remain as secondary belt-and-suspenders checks.
- Candidate-bound send and approval routes call the shared validator even when campaign context cannot be resolved, so compensation-topic leaks fail closed without salaryMin/salaryMax.
- Approval route resolves workspace state to pass campaign salaryMin/salaryMax and forbidden fields when available.
- Candidate prompt delimiter injection is neutralized through `sanitizeCandidateText()` before autopilot interpolates inbound text between `CANDIDATE_REPLY` sentinels.
- Candidate public role context scrubs free-text compensation fragments such as `circa 100k` before prompt construction.
- Graph planner/outreach and Hermes outreach prompts include `DISCLOSURE_SYSTEM`.
- Graph outreach validation now passes the forbidden internal list through `disclosureInternalFromCampaignLike()`.
- Email reply classification now treats inbound prompt-injection text as a human-review signal, matching WhatsApp inbound behavior.
