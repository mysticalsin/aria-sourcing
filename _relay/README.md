# `_relay/` — agent working-state, not product docs

This directory is the multi-agent build system's hand-off / relay memory. It is **not**
product or operational documentation — don't treat anything here as the source of truth
for how the product works or how to deploy it.

- **Current state:** [`HANDOFF.md`](HANDOFF.md) — the live baton between sessions.
- `archive/` — dated snapshots of past hand-offs.
- `research/` — background research notes from earlier waves.
- `codex-findings.md`, `PLAN.md`, dated audit notes — historical working artifacts.

For real documentation, start at [`../docs/README.md`](../docs/README.md). For release
posture, see [`../production-readiness/STATUS.md`](../production-readiness/STATUS.md).
