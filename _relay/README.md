# `_relay/` — agent working state, not product docs

The hand-off memory shared by the AI tools working on this repository (see
[`../AGENTS.md`](../AGENTS.md)). Nothing here is the source of truth for how the
product works or how to run it.

- [`HANDOFF.md`](HANDOFF.md) — the live baton: current state, next steps,
  decisions not to relitigate.
- [`codex-findings.md`](codex-findings.md) — open audit findings only.
- `archive/` — dated snapshots of past batons, closed findings
  (`codex-findings-closed-2026-11-03.md`) and the July 2026 plans, audits,
  research and incident records (`2026-07/`), superseded by the 2026-10-26
  scope reset. Never deleted.

For real documentation, start at [`../docs/README.md`](../docs/README.md).
