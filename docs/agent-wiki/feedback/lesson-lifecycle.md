# Lesson lifecycle

```
draft → proposed → canonical → superseded
                 ↘ rejected
```

| Status | Who sets it | Meaning |
| --- | --- | --- |
| draft | agent/operator | Working note; may be incomplete |
| proposed | feedback pipeline | Awaiting human review |
| canonical | human promote | Safe for agent recall |
| superseded | compaction | Replaced by a newer note ID |
| rejected | human | Do not use; keep for audit |

Promotion of **DB** lessons still requires independent admin review (0027).
Wiki canonicalization mirrors that discipline for Markdown recall.
